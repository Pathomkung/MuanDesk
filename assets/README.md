# Assets

`icon.svg` is MuanDesk's original white five-bar wave mark on a red/pink disc, with a
transparent exterior. It uses no official Google/YouTube logo and uses the project's
GPL-3.0-only license. Regenerate `icon.png` and multi-resolution `icon.ico` with `npm run icons`.

`google-domains.txt` is Google's factual country-domain list, downloaded from
https://www.google.com/supported_domains on 2026-11-12. It restricts navigation to account
service hosts. It contains no account export, cookies, credentials or personal data.
